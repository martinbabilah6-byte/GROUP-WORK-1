# Circuit Breaker and Fuse Selection System

This project contains a C++ program that helps estimate a suitable circuit breaker or fuse rating for one or more electrical circuits.

## Overview

The program:
- prompts for the circuit name, supply voltage, and total load power
- validates that the input values are positive
- calculates the load current using
  I = P(total)/V
- calculates the design current using
  - I_{design} = I(load) x 1.25
- recommends a standard protection device rating from a predefined list
- displays the report in the console and saves it to a text file

Features

- Supports multiple circuits in one run
- Validates input values before processing
- Recommends a standard protection rating from the following list:
  - 6 A
  - 10 A
  - 16 A
  - 20 A
  - 25 A
  - 32 A
  - 40 A
  - 63 A

## Files

- merged_program.cpp - the main C++ source code
- protection_report.txt - output report generated by the program

## How to Compile and Run

On Windows with g++ installed, use:

```bash
g++ merged_program.cpp -o merged_program.exe
merged_program.exe
```

## Program Usage

1. Run the executable.
2. Enter the number of circuits to assess.
3. For each circuit, enter:
   - circuit name
   - supply voltage in volts
   - total load power in watts
4. The program will display the protection report and save it to protection_report.txt.

## Example Output

The program prints a report including:
- circuit name
- load current
- design current
- recommended device rating
- protection status

## Algorithm

1. Display a welcome message and project title.
2. Ask the user how many circuits need to be assessed.
3. For each circuit:
   - input the circuit name, supply voltage, and total power
   - check whether the voltage and power values are positive
   - if invalid, ask the user to re-enter the values
   - calculate load current using $I = \frac{P}{V}$
   - calculate design current using $I_{design} = 1.25 \times I$
   - compare the design current with standard protection ratings
   - select the smallest standard rating that is greater than or equal to the design current
   - display and save the protection report
4. Save all reports to protection_report.txt.
